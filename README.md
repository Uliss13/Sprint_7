# Sprint_7: API-тесты Яндекс.Самокат

Проект по автоматизации тестирования API учебного сервиса «Яндекс.Самокат» (Практикум, 7-й спринт).

## Стек
- Python 3.9
- pytest 8.4.2
- requests 2.32.5
- allure-pytest 2.16.2

## Структура проекта
- `conftest.py` — Фикстуры pytest (создание/удаление курьера)
- `data.py` — Ожидаемые коды ответов и сообщения об ошибках
- `urls.py` — Эндпоинты API
- `helpers.py` — Вспомогательные методы (регистрация курьера)
- `tests/test_courier_create.py` — Тесты ручки «Создание курьера»
- `tests/test_courier_login.py` — Тесты ручки «Логин курьера»
- `tests/test_order_create.py` — Тесты ручки «Создание заказа»
- `tests/test_order_list.py` — Тесты ручки «Список заказов»
- `allure-report/` — Сгенерированный HTML-отчёт Allure

## Реализованные проверки

### Создание курьера (`POST /api/v1/courier`)
- Успешное создание курьера (201).
- Ошибка при создании дубликата (409, текст ошибки).
- Ошибка при отсутствии обязательных полей `login` или `password` (400, текст ошибки).

### Логин курьера (`POST /api/v1/courier/login`)
- Успешная авторизация (200, наличие `id`).
- Ошибка при неверном пароле (404).
- Ошибка при отсутствии обязательных полей (400).
  > **Известный баг API:** при полном отсутствии поля `password` сервер уходит в таймаут и возвращает 504 Gateway Timeout вместо 400. Тест помечен как `xfail`.

### Создание заказа (`POST /api/v1/orders`)
- Параметризованный тест по цветам: `BLACK`, `GREY`, оба цвета, без цвета (201, наличие `track`).

### Список заказов (`GET /api/v1/orders`)
- Проверка успешного ответа (200) и структуры тела (наличие `orders` и `pageInfo`).

## Запуск тестов и генерация отчёта

1. Активировать виртуальное окружение:
   `source .venv/bin/activate`

2. Запустить тесты с сохранением результатов для Allure:
   `pytest --alluredir=allure-results`

3. Сгенерировать HTML-отчёт:
   `allure generate allure-results -o allure-report --clean`

4. Открыть отчёт:
   `allure open allure-report`
